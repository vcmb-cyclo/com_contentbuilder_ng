# Spécifications internes

Ce dossier contient les spécifications fonctionnelles et techniques utilisées
pour maintenir ContentBuilder NG avec l'aide d'assistants de développement.

Ces documents sont internes au dépôt GitHub privé. Ils ne constituent pas une
documentation distribuée avec l'extension et ne doivent jamais être inclus dans
les paquets ZIP installables ni dans les artefacts de release. Le dossier porte
aussi l'attribut Git `export-ignore` pour l'exclure des archives créées avec
`git archive`.
